================================================
  FITFINDER AI — HOW TO RUN THIS PROJECT
================================================

WHAT IS INSIDE THIS ZIP:
  fitfinder/
  ├── backend/    ← The server (Node.js + MongoDB)
  └── frontend/   ← The website (React)


STEP 1 — INSTALL NODE.JS (only once)
--------------------------------------
Go to: https://nodejs.org
Download and install the LTS version (the green button).
After installing, open a terminal and type:
  node --version
You should see something like: v20.0.0


STEP 2 — SET UP FREE MONGODB DATABASE
---------------------------------------
1. Go to: https://mongodb.com/atlas
2. Sign up for free
3. Create a free cluster (M0 tier — pick any region)
4. In "Database Access" → Add a user with username + password
5. In "Network Access" → Add IP: 0.0.0.0/0 (allow all)
6. Click Connect → Drivers → Copy the connection string
   It looks like: mongodb+srv://username:password@cluster0.xxxx.mongodb.net/


STEP 3 — CONFIGURE THE BACKEND
---------------------------------
1. Open the "backend" folder
2. Find the file called ".env.example"
3. Copy it and rename the copy to ".env" (just ".env", no other name)
4. Open ".env" and fill in:
   - MONGO_URI  = paste your connection string from Step 2
                  (replace <password> with your actual password)
   - JWT_SECRET = type any long random text e.g: fitfinder_my_secret_2025
   - GROQ_API_KEY = your Groq key (OPTIONAL — chatbot works without it)


STEP 4 — START THE BACKEND
-----------------------------
Open a terminal (Command Prompt on Windows, Terminal on Mac).
Type these commands one by one:

  cd path/to/fitfinder/backend
  npm install
  npm run seed
  npm run dev

You should see:
  ✅ MongoDB connected
  🚀 Backend running at http://localhost:5000

KEEP THIS TERMINAL OPEN. Do not close it.
Test it works: open http://localhost:5000/api/health in your browser.
You should see: {"status":"OK","message":"FitFinder backend is running!"}


STEP 5 — START THE FRONTEND (WEBSITE)
----------------------------------------
Open a SECOND terminal (keep the first one open!).
Type these commands:

  cd path/to/fitfinder/frontend
  npm install
  npm start

Your browser will automatically open at: http://localhost:3000
The website is now running!


STEP 6 — TEST IT
------------------
1. Go to http://localhost:3000
2. Click "Sign Up" and create an account
3. Try searching "Bhopal" or "Indore" for gyms
4. Try the AI Chatbot, BMI Calculator, Diet Plans


TROUBLESHOOTING
----------------
Problem: "NetworkError" or login not working
Fix: Make sure the backend is running (Step 4). Check Terminal 1 is open.

Problem: "MongoDB connection failed"
Fix: Check MONGO_URI in your .env file.
     Make sure your IP is allowed in MongoDB Atlas Network Access.
     Make sure the password has no special characters like @ or /.

Problem: Port 3000 already in use
Fix: React will ask "Use port 3001?" — press Y.

Problem: npm install fails
Fix: Make sure you are INSIDE the correct folder (cd into it first).

TECH STACK (simple explanation)
---------------------------------
React     = The website you see (runs in browser)
Node.js   = The server brain (runs on your computer)
Express   = Makes it easy to create server routes/APIs
MongoDB   = The database that stores users and gyms
Mongoose  = The helper that connects your code to MongoDB
JWT       = Security tokens for login (like a wristband)
bcrypt    = Scrambles passwords so they are safe in database
Groq      = Powers the AI chatbot (optional)
